# 双语深度精读讲义

一篇英文原文 → 一份逐段拆解的讲义：双语对照、词条详解、短语与固定搭配、长难句拆解、
语法点归位、论证分析，最后导出成可打印的 Word 与 PDF。

**这份 skill 只做「读」这一侧**：重点是高考重点词汇、短语、固定搭配、长难句解析与语法点。
写作产出（写作素材库、读后续写素材、单元写作专题）不在范围内，不要自行加回来。

分析方法与体例的完整定义在 [`references/method.md`](references/method.md)，动笔前读它。

**先判这篇是教材课文还是外刊，两侧读不同的文件**（骨架里的六条硬性约束是排版层的，两侧共用）：

| | 教材课文（高考） | 外刊文章（雅思） |
|---|---|---|
| 骨架 | [`template.md`](references/template.md) | [`template-ielts.md`](references/template-ielts.md) |
| 靶子 | [`gaokao-targets.md`](references/gaokao-targets.md) | [`ielts-targets.md`](references/ielts-targets.md) |
| 主线 | 知识点 | 论证分析 + 写作迁移 |
| 每块必做 | 🔗 短语与固定搭配 / 🔍 长难句拆解 / 🧩 语法聚焦 | 词条内的 外刊写作赏析 / 🎓 IELTS 使用提醒 |
| 词条末尾 | 掌握分级 ✓✓✓/✓✓/✓/⚠️（要不要背） | 迁移分级 ✓✓/✓/✧/⚠️（能不能搬进作文） |
| 文末附录 | 📐 考点扫描 + ✅ 学完自测 | 无 |

**两侧都不是"另一侧减几块"**：高考主要考知识点，所以教材那三块和精读并列、不是附属品；
雅思考能力，所以外刊的正主是词条里那句「这个表达能不能搬进我自己的作文」——
判据是语域，不是难度。

改排版、或产出与原件不像时，读 [`references/style-spec.md`](references/style-spec.md)——从《外刊精读》原件 OOXML 提取的完整样式规格。

## 流程

### 1. 取原文，定一句"真问题"

拿到原文（PDF 教材先试 `pdftotext -f N -l M -layout`，有文字层就不必读图）。通读后写出一句话：**这篇文章表面写 X，真正要问的是 Y**。

导读和结尾都由这句话派生，所以它必须是一个追问，不是内容复述。

**完成标准**：这句话能写成「不是 A，而是 B」的形式。

### 2. 判文体，再按功能切块

**先判文体**：叙事 / 说明 / 议论。这一步决定精读那条支线怎么读——议论文走精读五套路，
叙事文的主线是人物动机弧与动作链（用论证工具去读叙事文，推理判断题的依据会整块读丢）。

一块 = 一次完整的功能推进，**不必等同原文段落**。推理最密的长段拆成上/下两块；连续的铺垫段可以合并。

**完成标准**：写下文体判断；每一块都能用一句话说清它在全文里干了什么。

### 3. 逐块做三遍标注（教材课文五遍）

同一块反复过，每遍只找一类东西：

1. **词** —— 多义易误解、隐喻有画面、作者的态度词、同根词串。
   教材课文再叠一层高考三维：课标内外 / 构词法可拆 / 熟词生义
2. **短语与固定搭配** —— 动词短语、动词/形容词/名词的固定介词搭配、固定句型骨架、
   高频名词搭配。**这一遍单独走，不要顺手并进第 1 遍**：搭配是靠整块扫才扫得全的，
   夹在词条里找永远只找得到最显眼的那几条
3. **论证动作** —— claim / concession / evidence / counterpoint / 反差 / 因果链
4. **（教材课文加这一遍）语法点与长难句** —— 按 gaokao-targets.md 的「高中语法十二类」
   扫本块实际出现的语法点，逐类记下原句片段；同时圈出长难句候选（选句标准见 method.md）
5. **（教材课文加这一遍）语法填空十类考点** —— 各找原句例证，尤其第 6 类介词，
   它和第 2 遍的固定搭配是同一批料，扫的时候一并记下
6. **（外刊加这一遍）语域判断** —— 把第 1、2 遍挑出来的表达逐条判能不能迁移到雅思写作：
   落在五类语域信号（新闻评论修辞 / 文学隐喻 / 隐含褒贬 / 网络俚语 / 夸张调侃）里的判 ⚠️
   或 ✧，并同时想好替代表达。判据在 ielts-targets.md

**完成标准**：三份清单都非空（教材五份 / 外刊四份），第一份里每一条都带分级，
第二份里每条搭配都有原句出处；〔教材〕第四份里每块都至少归位到一类语法点；
〔外刊〕第六份里每条都判出了迁移档位，⚠️ 与 ✧ 都想好了替代表达。

### 4. 写词条

按**词条七件套**写（method.md 有定义与样例）。三条硬性要求：

- 每个词条都要**原文回填**（原句 + 译文），否则等于抄词典
- 每个词条都要给分级，两侧问的不是同一件事：
  - 〔教材〕**掌握分级**——要不要背：✓✓✓ 必背必默 / ✓✓ 熟练认读 / ✓ 认得即可 / ⚠️ 表外只读
  - 〔外刊〕**迁移分级**——能不能搬进自己的作文：✓✓ 直接迁移 / ✓ 可迁移但不必常用 /
    ✧ 部分迁移 / ⚠️ 只读不迁。判据是语域，写在 `🎓 IELTS 使用提醒` 里
- ⚠️ 档**必须**给出"那该用什么"：〔教材〕课标内的高频同义词（`epidemiology` ⚠️，
  但 `epidemic` / `pandemic` 必须掌握）；〔外刊〕雅思里的替代表达
  （`a torrent of criticism` ⚠️ → `widespread criticism` / `be widely criticized for`）
- 〔外刊〕✧ 档要把修辞层与学术层切开：`a minor literature of…` 不迁移，
  但 `literature` 的学术义与 `a growing body of literature on…` 必须掌握

**完成标准**：每个词条都有原文回填与分级；所有 ⚠️ 条目都给了替代/对应词；
〔外刊〕每个词条都有 `外刊写作赏析` 与 `🎓 IELTS 使用提醒` 两块。

### 5. 写 `🔗 短语与固定搭配`

教材课文每块必做，外刊讲义可选。这是「短语、固定搭配」这条重点的正主，
词条里的搭配家族只是它的补充：**家族是围着一个词展开，这一块是围着整块课文扫**。

四列表格：`短语 / 含义 / 原句片段 / 考点`。四类都要扫（method.md 有判据与样例）：

- **动词短语** —— `attend to`、`account for`、`be to blame for`
- **固定介词搭配** —— 动词/形容词/名词后的介词，**语法填空无提示词最大的一类**，
  漏了这类等于没做这个模块
- **固定句型骨架** —— `It is + adj. + that…`、`not until… did…`、`so… that…`
- **高频名词搭配** —— `take measures`、`make a difference`、`draw a conclusion`

两条硬性要求：

- 每条都要**原句片段**，凭空罗列的搭配表和词典附录没有区别
- 「考点」列写清它在高考里以什么形式出现（`语法填空·介词` / `完形·词汇复现` /
  `熟词生义`），写不出考点的条目说明它只是普通词组，删掉

本块搭配确实少于 3 条时，把它并进上一块统一给，并写一句说明——不要为了凑数编搭配。

**完成标准**：每块 ≥3 条；介词搭配那一类非空；每条都有原句片段与考点标注。

### 6. 写句法块：长难句拆解 + 语法聚焦

教材课文专用，**每块两个模块都必做**——高考主要考知识点，这两块是知识点的正主，
不是精读的边角料。外刊讲义跳过这一步。

**🔍 长难句拆解**：每块选 1~2 句，按 method.md 的五步法写（切意群 → 抽主干 → 剥修饰 →
画嵌套树 → 直译 + 考点挂钩）。两条硬性要求：

- 选**考点密度最高**的句子，不是最长的句子
- 第五步的 `⇢ 考点挂钩` 不能省。只拆不挂，等于把语法课上成了语文课

本块确实没有达标的长难句，就写成 `### 🔍 长难句拆解｜本块无长难句` 加一句说明——
留一行比空着好，别让人以为漏了。

**🧩 语法聚焦**：分两段，顺序不能反。先出**归位表**（本块实际出现的语法点按十二类归位，
三列：原句片段 / 语法点 / 为什么必须这么用），再**深讲一个点**——优先取单元语法项，
本块没有就挑归位表里最容易错的那一个。一块只深讲一个，挑不出就只留归位表。

**完成标准**：每块都有这两个模块；每条长难句五步齐全（切意群 / 主干 / 剥修饰 / 嵌套图 / 直译）并挂了考点；
每张归位表的第三列都是解释，不是"这里用了 X"。

### 7. 写精读

每块一个 `📖 精读`，**先写标题再写正文**——标题是一句论点（`真正 X 的，不是 A，而是 B` 或 `为什么 X，却 Y？`）。标题写不出来说明这块还没读透，回到第 3 步。

正文用 method.md 里的五套路：论证链条命名、反差定位、因果链箭头图、立场精确化、竞争性解释提醒。
教材课文在末尾补一行 `⇢ 题型对接`，把这段结构分析折算成解题线索——**挂不上就不加**。

**完成标准**：每块都有论点式标题；全文至少 2~3 处用 `→` 把逻辑画成箭头图；至少 1 处给出竞争性解释。

### 8. 最后写导读、结尾与两个附录

写完全部段落块之后再回头写【导读】和【写在最后】，确保与实际内容咬合。结尾要回扣第 1 步那句真问题，并双语引用文中金句。

教材课文在结尾之后还有两个附录，**它们不是可选项**（骨架见 template.md 末段）：

- `📐 附：语法填空考点扫描` —— 十类考点逐类归档，覆盖不到的类明写「本篇未覆盖」。
  料就是第 3 步第 5 遍标注的成果，第 6 类介词直接从各块的 🔗 表汇总
- `✅ 学完自测` —— 词汇自查 / 搭配自查 / 长难句自查 / 语法自查 + 课本活动对接。
  只考本讲义讲过的东西，不引入新语料

### 9. 分段落盘：长文不要攒一整篇再落笔

篇幅长（教材课文这类通常 15~30 页 A4）时，如果攒着把全文内容在一次回复里想全、写全，
再一次性 Write 整个文件，容易在服务端触发超长单次响应中断——而且中断发生在第一次落盘
**之前**，等于全部工作白做，还不会留下任何可恢复的痕迹。正确做法：

- 读完原文、做完文体判断和三/五遍标注后，**先用 Write 落一个骨架文件**：YAML front
  matter + 封面区 + 段落块标题占位列表（导读和写在最后先留占位，仍按第 8 步的顺序最后补实）。
- 之后用 **Edit** 逐个模块追加：每写完一个段落块（En/译对照 + 表达清单 + 词汇注释 +
  🔗短语与固定搭配 + 🔍长难句拆解 + 🧩语法聚焦 + 📖精读）就是一次 Edit，写完就落盘，
  不要攒着几个模块一起生成再一次性写入。教材课文的段落块有七个模块，一块的体量不小，
  更要一块一落。
- 每次 Edit 的新增内容控制在约 100~250 行（一个词条组、一个精读块这种粒度），不要在
  一次工具调用里塞入大半篇剩余内容。
- 中途如果因为任何原因中断，重新开始时先 Read 现有文件判断写到哪一步，接着往下续写，
  **不要清空重写**。

### 10. 构建

```bash
~/.claude/skills/intensive-reading/scripts/build.sh "<讲义.md>"
```

同目录产出 `.docx` 与 `.pdf`（A4，内嵌字体）。讲义开头用 YAML front matter 声明页眉页脚：

```yaml
---
header: 人教版 选择性必修 第二册  ·  双语深度精读讲义
footer: 选必二 Unit 1  ·  John Snow
---
```

脚本自动处理四件导出期的事，**不要在源文件里迁就它们**：源文件照常用 emoji、
管道表格，列表也照常紧跟在文字行后面。

- LibreOffice 对 emoji 及 `▶ ⚠ ✔` 无字形，导出时换成几何符号
- pandoc 输出的空 `<w:tblGrid/>` 会让表格塌成一列，导出时按内容宽度补列宽
- `--toc` 在 docx 里只是个待更新的域，导出时改用实体目录
- 紧跟文字行的 `- ` 列表本会被并进上一段，构建时开扩展纠正

**构建失败就是真的有问题，别绕过。** 这三类失败都是静默的——产物照样生成、页数照样对，
所以脚本把它们做成了硬性门禁，任一不过就整条管线停住、**不落盘任何产物**：

- 出现 GLYPH_MAP 与 SAFE_DECOR 都没覆盖的装饰符号 → 报出行号与码位，去补映射
- 封面 / 导读方框 / 精读方框 / En 行 / 译文 / 词条头 任一识别数为 0 → 报出缺哪个，
  对照 template.md 的硬性约束改讲义结构
- 成品 PDF 里出现字面 `**` → 反引号内嵌套了加粗（见 template.md 第六条约束），
  报出带上下文的那几行，逐行改成 `*外层斜体 **内层加粗** *` 或把加粗移出反引号

最后那条历史上是被漏得最多的一类问题（脚本以前不查，靠人肉看渲染截图）。现在它由
`build.sh` 对成品 PDF 跑 `pdftotext … | grep -oP '\*\*[^ ]'` 自动拦，**不要再手工复查**，
但也不要在源文件里为了绕它而牺牲写法——改法只有上面那两种。

**产出规模不设上限。** 讲义的价值在覆盖度，不在页数——**宁全不省**：
搭配能扫多少扫多少，考点扫描十类逐类都要有结论，词条该写透就写透。
不要为了「别太长」压缩任何模块，也不要把内容挪进附录来让主体显短。

### 11. 自检

逐条核对，不合格的回到对应步骤。**做外刊讲义时用 template-ielts.md 末尾那张单子**，
带〔教材〕的条目一律不适用：

- [ ] 导读结尾是一个真问题，不是内容复述
- [ ] 每块四件套齐全（双语对照 / 表达清单 / 词汇注释 / 精读）
- [ ] 〔教材〕每块都有 `🔗 短语与固定搭配`，≥3 条，每条都带原句片段与考点标注
- [ ] 〔教材〕搭配表里**介词搭配非空**（语法填空无提示词最大的一类）
- [ ] 〔教材〕每块都有 `🔍 长难句拆解`，本块确无长难句的**明写「本块无长难句」**
- [ ] 〔教材〕每条长难句五步齐全（切意群 / 主干 / 剥修饰 / 嵌套图 / 直译），
      且挂了 `⇢ 考点挂钩`
- [ ] 〔教材〕每块都有 `🧩 语法聚焦`，归位表按十二类扫过本块实际出现的语法点，
      第三列是"为什么必须这么用"而不是"这里用了 X"
- [ ] 英中**按句**对照，没有整段堆译文
- [ ] 每个词条都有原文回填
- [ ] 搭配家族 ≥3 条
- [ ] 〔教材〕每个词条都有掌握分级（✓✓✓/✓✓/✓/⚠️ 四档）；⚠️ 类都挂了要掌握的对应词
- [ ] 〔教材〕✓✓✓ 只给必背必默项（课标核心词 / 单元语法项 / 高频考点），没有滥发
- [ ] 〔外刊〕每个词条都有 `外刊写作赏析` + `🎓 IELTS 使用提醒`，分级四档齐全，
      ⚠️ 给了替代表达、✧ 切开了修辞层与学术层
- [ ] 〔教材〕文末有 `📐 语法填空考点扫描` 附录，十类考点逐类扫过，覆盖不到的类**明写「本篇未覆盖」**
- [ ] 〔教材〕文末有 `✅ 学完自测`，四项自查（词汇 / 搭配 / 长难句 / 语法）齐全，且只考讲过的内容
- [ ] 〔教材〕词条与课后练习双向咬合：某词在 Learning About Language 考过就在词条里标出
- [ ] 〔教材〕表外词都是 ⚠️；熟词生义词条同时给了常见义与本文义
- [ ] 每块精读都是论点式标题
- [ ] ≥2 处箭头逻辑图
- [ ] ≥1 处竞争性解释或批判性提醒
- [ ] 结尾回扣导读的真问题，并双语引用金句
- [ ] `.docx` 与 `.pdf` 已生成且构建无报错，抽查过封面页、词条页、表格页的实际渲染

## 两种源文的差异

**外刊**：主线是论证分析 + 写作迁移。段落块只做四件套（不做 🔍 / 🧩 / 📐 / ✅，
`🔗` 可选），但**词条内部多两个必做模块**，骨架见 template-ielts.md：

- `外刊写作赏析` —— 作者没用普通的 X 而用了 Y；Y 多出来的是什么；这一段为什么需要它
- `🎓 IELTS 使用提醒` —— **外刊讲义的正主**：给迁移分级（✓✓ 直接迁移 / ✓ 可迁移但不必常用 /
  ✧ 部分迁移 / ⚠️ 只读不迁）并说清理由。⚠️ 档必须给雅思里的替代表达，✧ 档必须把修辞层与
  学术层切开，✓✓ 档要写清接哪个话题域。判据是**语域**（新闻评论修辞 / 文学隐喻 / 隐含褒贬 /
  网络俚语 / 夸张调侃这五类信号一律不迁移），不是难度——Lexical Resource 看的是恰当，不是罕见

另有两块看料再做：`🎓 IELTS 写作迁移`（一篇 1~3 处，把几个表达串成一条完整论证链）、
`📈 Task 1 迁移`（只在有数据段时做，讲数据之间**关系**的变化）。
精读末尾挂 `⇢ 能力对接` 而不是题型对接——雅思没有一对一的题型判据。
外刊版的自检清单在 template-ielts.md 末尾。

**教材课文**：主线是知识点，四件套之外每块加三个必做模块，另加一张附录表和一条咬合要求——

- `🔗 短语与固定搭配`（**每块必做**）：动词短语 / 固定介词搭配 / 句型骨架 / 名词搭配
- `🔍 长难句拆解`（**每块必做**）：五步法拆句 + 考点挂钩
- `🧩 语法聚焦`（**每块必做**）：先按十二类归位本块语法点，再深讲单元语法项
- `📐 语法填空考点扫描`（附录）：十类考点逐类归档，覆盖不到的明说缺
- 词条与课后练习**双向咬合**：某词在 Learning About Language 哪道题考过，就在词条里标出来

另外精读末尾加一行 `⇢ 题型对接`，把结构分析折算成解题线索（挂不上就不加）。

**为什么教材版要多出这些**：雅思是正儿八经的能力考试，读得快、抓得住主旨就能得分；
高考级别更低，主要考的是知识点——重点词汇、短语与固定搭配、长难句、语法点。
所以外刊那套论证分析在教材讲义里降为一条支线（仍然要有，`⇢ 题型对接` 就是它的变现口），
知识点那三块升为必做。

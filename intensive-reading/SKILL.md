# 双语深度精读讲义

一篇英文原文 → 一份逐段拆解的讲义：双语对照、词条详解、迁移分级、论证分析，最后导出成可打印的 Word 与 PDF。

分析方法与体例的完整定义在 [`references/method.md`](references/method.md)，动笔前读它。骨架在 [`references/template.md`](references/template.md)——**开头的五条硬性约束先看**，违反了排版会退回默认样式。

做**教材课文**还要读 [`references/gaokao-targets.md`](references/gaokao-targets.md)——分值地图、语法填空十类考点、读后续写四类素材、词条的高考三维、精读的题型对接表。外刊讲义不用。
改排版、或产出与原件不像时，读 [`references/style-spec.md`](references/style-spec.md)——从《外刊精读》原件 OOXML 提取的完整样式规格。

## 流程

### 1. 取原文，定一句"真问题"

拿到原文（PDF 教材先试 `pdftotext -f N -l M -layout`，有文字层就不必读图）。通读后写出一句话：**这篇文章表面写 X，真正要问的是 Y**。

导读和结尾都由这句话派生，所以它必须是一个追问，不是内容复述。

**完成标准**：这句话能写成「不是 A，而是 B」的形式。

### 2. 判文体，再按功能切块

**先判文体**：叙事 / 说明 / 议论。这一步决定后面谁是主线——议论文走精读五套路，
叙事文必须同时拆续写素材（25 分，用论证工具读叙事文会整块漏掉）。

一块 = 一次完整的功能推进，**不必等同原文段落**。推理最密的长段拆成上/下两块；连续的铺垫段可以合并。

**完成标准**：写下文体判断；每一块都能用一句话说清它在全文里干了什么。

### 3. 逐块做三遍标注（教材课文四遍）

同一块反复过，每遍只找一类东西：

1. **语言点** —— 多义易误解、隐喻有画面、搭配成家族、作者的态度词、同根词串。
   教材课文再叠一层高考三维：课标内外 / 构词法可拆 / 熟词生义
2. **论证动作** —— claim / concession / evidence / counterpoint / 反差 / 因果链
3. **可迁移表达** —— 逐条打上**迁移分级**（✓✓✓ 必背 / ✓✓ 建议迁移 / ✓ 认识慎用 / ⚠️ 只读不写）
4. **（教材课文加这一遍）考点与续写料** —— 语法填空十类考点各找原句例证；
   叙事文另拆动作链 / 心理梯度 / 环境五感

**完成标准**：三份（教材四份）清单都非空，第三份里每一条都带分级。

### 4. 写词条

按**词条七件套**写（method.md 有定义与样例）。两条硬性要求：

- 每个词条都要**原文回填**（原句 + 译文），否则等于抄词典
- ⚠️ 级的词条**必须**给替换方案 + 一个例句

**完成标准**：每个词条都有原文回填；所有 ⚠️ 条目都有替换方案。

### 5. 写精读

每块一个 `📖 精读`，**先写标题再写正文**——标题是一句论点（`真正 X 的，不是 A，而是 B` 或 `为什么 X，却 Y？`）。标题写不出来说明这块还没读透，回到第 3 步。

正文用 method.md 里的五套路：论证链条命名、反差定位、因果链箭头图、立场精确化、竞争性解释提醒。
教材课文在末尾补一行 `⇢ 题型对接`，把这段结构分析折算成解题线索——**挂不上就不加**。

**完成标准**：每块都有论点式标题；全文至少 2~3 处用 `→` 把逻辑画成箭头图；至少 1 处给出竞争性解释。

### 6. 最后写导读与结尾

写完全部段落块之后再回头写【导读】和【写在最后】，确保与实际内容咬合。结尾要回扣第 1 步那句真问题，并双语引用文中金句。

### 7. 构建

```bash
~/.claude/skills/intensive-reading/scripts/build.sh "<讲义.md>"
```

同目录产出 `.docx` 与 `.pdf`（A4，内嵌字体）。讲义开头用 YAML front matter 声明页眉页脚：

```yaml
---
header: 人教版 选择性必修 第二册  ·  双语深度精读讲义
footer: 选必二 Unit 1  ·  John Snow
---
```

脚本自动处理四件导出期的事，**不要在源文件里迁就它们**：源文件照常用 emoji、
管道表格，列表也照常紧跟在文字行后面。

- LibreOffice 对 emoji 及 `▶ ⚠ ✔` 无字形，导出时换成几何符号
- pandoc 输出的空 `<w:tblGrid/>` 会让表格塌成一列，导出时按内容宽度补列宽
- `--toc` 在 docx 里只是个待更新的域，导出时改用实体目录
- 紧跟文字行的 `- ` 列表本会被并进上一段，构建时开扩展纠正

**构建失败就是真的有问题，别绕过。** 缺字形和角色认错都是静默的——产物照样生成、
页数照样对，所以脚本把它们做成了硬性检查：

- 出现 GLYPH_MAP 与 SAFE_DECOR 都没覆盖的装饰符号 → 报出行号与码位，去补映射
- 封面 / 导读方框 / 精读方框 / En 行 / 译文 / 词条头 任一识别数为 0 → 报出缺哪个，
  对照 template.md 的硬性约束改讲义结构

### 8. 自检

逐条核对，不合格的回到对应步骤：

- [ ] 导读结尾是一个真问题，不是内容复述
- [ ] 每块四件套齐全（双语对照 / 表达清单 / 词汇注释 / 精读）
- [ ] 英中**按句**对照，没有整段堆译文
- [ ] 每个词条都有原文回填
- [ ] 搭配家族 ≥3 条
- [ ] 每条迁移提示都有分级（✓✓✓/✓✓/✓/⚠️ 四档）；⚠️ 类都有替换方案 + 例句
- [ ] ✓✓✓ 只给必背项（单元语法项 / 高频考点 / 可套用的句型骨架），没有滥发
- [ ] 〔教材〕语法填空十类考点逐类扫过，覆盖不到的类**明写「本篇未覆盖」**
- [ ] 〔教材·叙事文〕续写素材四类齐全，心理动词按强度排序而非出现顺序
- [ ] 〔教材〕表外词都是 ⚠️；熟词生义词条同时给了常见义与本文义
- [ ] 每块精读都是论点式标题
- [ ] ≥2 处箭头逻辑图
- [ ] ≥1 处竞争性解释或批判性提醒
- [ ] 结尾回扣导读的真问题，并双语引用金句
- [ ] `.docx` 与 `.pdf` 已生成且构建无报错，抽查过封面页、词条页、表格页的实际渲染
- [ ] 抽查时确认搭配家族是分行的列表，不是挤成一行的连字符串

## 两种源文的差异

**外刊**：迁移目标是雅思学术写作，用 `🎓 IELTS 使用提醒`。

**教材课文**：迁移目标是高考写作与读后续写，用 `🎓 高考迁移`；另加四个模块——

- `🧩 语法聚焦`：对接该单元的语法项，用课文原句当例证
- `🖊 续写素材`（叙事课文必做）：动作链 / 心理梯度 / 环境五感，读后续写 25 分靠这块
- `📐 语法填空考点扫描`：十类考点逐类归档，覆盖不到的明说缺
- 词条与课后练习**双向咬合**：某词在 Learning About Language 哪道题考过，就在词条里标出来

另外精读末尾加一行 `⇢ 题型对接`，把结构分析折算成解题线索（挂不上就不加）。
写作素材库分两栏：应用文与议论文（15 分）/ 读后续写（25 分）。

# 外刊讲义骨架（IELTS）

外刊/雅思那一侧的骨架。教材课文用 [`template.md`](template.md)。

**排版的六条硬性约束在 [`template.md`](template.md) 开头，两种源文都适用，这里不重复。**
迁移分级与语域判据见 [`ielts-targets.md`](ielts-targets.md)，读法见 [`method.md`](method.md)。

## 和教材骨架的五处差别

1. **封面没有单元字段。** 没有「单元主题 / 阅读策略 / 语法项」，换成刊物 · 作者 · 期号 · 主题标签
2. **每块只做四件套**：双语对照 / ✦ 表达清单 / 📖 词汇注释 / 📖 精读。
   不做 🔍 长难句拆解、🧩 语法聚焦、📐 语法填空考点扫描、✅ 学完自测——那四块对着高考知识点
3. **词条里多两个模块**：`外刊写作赏析`（作者为什么不用普通说法）与
   `🎓 IELTS 使用提醒`（能不能搬进自己的作文）。后者是外刊讲义的正主，**不是可选项**
4. **掌握分级换成迁移分级**：✓✓ 直接迁移 / ✓ 可迁移但不必常用 / ✧ 部分迁移 / ⚠️ 只读不迁。
   判据是语域，不是难度（`ielts-targets.md` 有四档判据与五类语域信号）
5. **精读末尾不挂题型**，挂能力对接（Task Response / Lexical Resource / Reading 能力），
   而且挂不上就不挂。雅思没有一对一的题型判据，硬挂是伪精确

`🔗 短语与固定搭配` 可做可不做：外刊里扫出一批正式搭配时值得单独成表，
考点列换成「迁移分级 + 话题域」；雅思不单考搭配，所以不强制。

## 自检（外刊版）

教材版那张单子里带〔教材〕的条目一律不适用，换成这几条：

- [ ] 每块四件套齐全（双语对照 / ✦ 表达清单 / 📖 词汇注释 / 📖 精读）
- [ ] 每个词条都有原文回填与**迁移分级**（✓✓ / ✓ / ✧ / ⚠️ 四档）
- [ ] 所有 ⚠️ 档都给了**替代表达**，所有 ✧ 档都把修辞层与学术层**切开**了
- [ ] ✓✓ 档写清了话题域，不是只写「可以用」
- [ ] 语域判断有依据：⚠️ 的理由能落到五类语域信号里的某一类
- [ ] 至少 1~3 处做到第 ③ 层迁移（`🎓 IELTS 写作迁移`），不是全篇只做同义词替换
- [ ] 遇到数据段做了 `📈 Task 1 迁移`；没有数据段则不做（不硬造）
- [ ] 每块精读都是论点式标题；≥2 处箭头逻辑图；≥1 处竞争性解释
- [ ] 全篇没有 🔍 / 🧩 / 📐 / ✅ 那四块（它们对着高考知识点，不是雅思）
- [ ] 精读末尾挂的是**能力对接**而不是题型对接，且挂不上的地方没有硬凑
- [ ] 结尾回扣导读的真问题，并双语引用金句
- [ ] 构建通过（字形 / 六角色 / 字面星号三道门禁都过了，产物才会落盘）

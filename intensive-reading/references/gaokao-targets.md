# 高考考点清单

写教材课文讲义时的靶子。**不是词表**——课标 3000 词表不入库，词条的课标内外判定
靠下面那组启发式；这里收的是「哪些东西一定会被考、以什么形式考」。

外刊讲义用不到这份文件，它服务的是 `method.md` 末节的教材附加模块。

## 分值地图

新课标卷通行结构（按自己省份的卷子核实；甲卷没有读后续写，有短文改错）：

| 部分 | 分值 | 考什么 | 讲义能供什么 |
|---|---|---|---|
| 阅读理解 | 37.5 | 细节 / 推理判断 / 主旨 / 词义猜测 | 精读的立场精确化、熟词生义词条 |
| 七选五 | 12.5 | 语篇衔接：代词回指 / 连接词 / 同义复现 | 论证链条命名、段落功能标注 |
| 完形填空 | 15 | 逻辑复现 / 词汇复现 / 语境辨析 | 因果链箭头图、近义辨析 |
| 语法填空 | 15 | 见下「十类考点」 | 语法填空考点扫描表 |
| 应用文 | 15 | 书信 / 通知 / 演讲稿 / 邀请函 | 写作素材库（应用文栏） |
| 读后续写 | **25** | 情节推进 / 情感动机 / 与原文呼应 | **续写素材**（当前最薄的一块） |

读后续写是单项分值最高的题。教育部考试院 2026 年评析点名的能力是「依据上下文推断
情感、理解行为动机」——这是续写和推理判断共用的内核，别只当作文题看。

## 语法填空十类考点

10 个空通常 6~7 个有提示词、3~4 个无提示词。**每篇讲义要做一遍扫描：
课文原句能覆盖哪几类，覆盖不到的明说缺**，别拿单元语法项充数。

**有提示词**（括号里给了原形）

| # | 考点 | 课文里找什么 |
|---|---|---|
| 1 | 词性转换 | 可派生的实词：`prevent→prevention`、`treat→treatment`、`infect→infection/infectious` |
| 2 | 时态语态 | 叙事文的时间层次，尤其过去完成时与一般过去时的对照 |
| 3 | 非谓语 | 分词作状语 / 定语，不定式作目的，`have sth done` |
| 4 | 形容词副词 | 比较级最高级、adj. 变 adv. |
| 5 | 主谓一致 | 集合名词、`statistics` 这类单复数变义词 |

**无提示词**

| # | 考点 | 课文里找什么 |
|---|---|---|
| 6 | 介词 | 动词/形容词的固定介词搭配——**最容易被讲义漏掉的一类** |
| 7 | 冠词 | 特指与泛指、序数词前、固定短语里的零冠词 |
| 8 | 代词 | it 的形式主语/宾语、those/that 替代、反身代词 |
| 9 | 连词 | 并列与转折、`so…that`、`not only…but also` |
| 10 | 关系词 | that/which/who/whose/where/when，以及 `the way` 后的三种写法 |

## 读后续写的四类素材

议论文表达在续写里几乎用不上。要从课文里另拆四样，**叙事课文尤其要拆**：

| 类 | 拆什么 | John Snow 里的现成料 |
|---|---|---|
| 动作链 | 连续动词 + 副词/介词短语，能串成一个连贯动作序列 | `began to investigate → marked on a map → suspected → had the handle removed` |
| 心理与情感 | 心理动词及其**强度梯度**，能排出递进 | `frustrated → never lost his desire → was determined → suspected` |
| 环境渲染 | 天气 / 光线 / 声音 / 气味，且服务于情绪 | `an outbreak hit London`、`polluted by raw waste` |
| 五感细节 | 看见 / 听见 / 闻到 / 触到的具体名词 | 水泵、地图、免费啤酒、死亡人数 |

拆的时候按**强度排序**而不是按出现顺序——续写得分靠情绪的层层推进，一份乱序的
心理动词清单学生用不上。

## 词条的三个高考维度

在 `method.md` 的五条筛选标准之外再过一遍，这三条是高考专属：

**① 课标内外判定**（不查表，用启发式）

| 判定 | 特征 | 处理 |
|---|---|---|
| 表内核心 | 义务教育到高中反复出现、构词能力强、日常语域 | 要求拼写 + 主动使用，✓✓ 或 ✓✓✓ |
| 表内低频 | 认得但很少自己用、语域偏正式 | ✓，注明分寸 |
| 表外 | 专业术语、拉希词源长词、学科专名 | ⚠️ 只读不写，说明「认识即可」 |

判不准就往严的一侧靠——把表内词标成 ⚠️ 只是浪费一条，把表外词标成 ✓✓ 会让
学生在作文里用错。`epidemiology` 是典型表外词：给 ⚠️，但要说清 `epidemic` 与
`pandemic` 是疫情类阅读的高频，必须掌握。

**② 构词法可拆性** —— 能拆前后缀的词优先选进注释，因为词性转换是语法填空第一大类。
拆完顺手挂上同族词串（`epi- + dem(o) + -ology`；`trans- + form`）。

**③ 熟词生义** —— 阅读的词义猜测题只考这个。判据是「学生认得这个词的常见义，
但本文用的是另一个义」：`see`（经历/出现）、`handle`（把手）、`raw`（未处理的）、
`waste`（污物）、`attend to`（照料）、`account for`（占比）、`address`（应对）。
这类词条**必须**同时给常见义与本文义，并明确标出这是熟词生义。

## 精读的题型对接

精读五套路本来是学术阅读工具，加一行 `⇢ 题型对接` 把它折算成解题线索：

| 精读做的事 | 对接题型 | 那句翻译 |
|---|---|---|
| 立场精确化 | 推理判断 | 作者的实际立场画出了边界，选项超出边界即干扰项 |
| 竞争性解释提醒 | 推理判断 | 过度归因是最常见的错误选项设计 |
| 论证链条命名 | 七选五 | 段落功能决定空格该填什么；代词回指与同义复现是定位线索 |
| 因果链箭头图 | 完形填空 | 完形主要考逻辑复现，箭头断在哪里就是空格在哪里 |
| 反差定位 | 主旨要义 | 反差处通常就是作者的态度所在 |
| 熟词生义词条 | 词义猜测 | 上下文线索：定义复现 / 举例 / 对比 / 因果 |

一处精读只挂一条，挂不上就不挂——硬凑的对接比不挂更糟。
